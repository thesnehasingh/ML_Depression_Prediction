# ML-Based Depression Prediction using Social Media Data

## 📌 Overview
This project uses Machine Learning and NLP techniques to predict depression based on social media text data.

## ⚙️ Technologies Used
- Python
- Scikit-learn
- Pandas, NumPy
- NLP (TF-IDF, Sentiment Analysis)

## 📊 Models Used
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score

## 🧠 Methodology
1. Data Preprocessing
2. Feature Extraction (TF-IDF)
3. Model Training
4. Evaluation & Comparison

## 🚀 Results
SVM performed best with highest accuracy.
